Часть 1

Команда print

print — вывести текст на экран

print("Привет, игрок!")
Привет, игрок!

Пишешь print(...) — Python показывает то, что внутри скобок.

Разбираем по частям

print("Привет, игрок!")
 │     │                │
 │     │                └─ закрывающая кавычка и скобка
 │     └─ текст в кавычках — то, что выведется
 └─ имя команды: print
  • Скобки ( ) — обязательно
  • Кавычки " " вокруг текста — обязательно
  • Пишем print маленькими латинскими буквами
ПРАКТИКА

Выведи на экран три строки:
твоё имя, любимую игру и фразу «Я учусь на Python».

Подсказка: нужно три команды print, каждая на своей строке.

Кавычки: двойные и одинарные

print("Всё хорошо")
print('Тоже хорошо')

print("Он сказал: 'привет'")     # кавычки разного вида — ок
print('Это "круто"')

Главное правило: чем строку открыл — тем и закрывай.

Несколько print — несколько строк

print("METEOR HUNT")
print("--------------")
print("1 - Играть")
print("2 - Выход")
METEOR HUNT -------------- 1 - Играть 2 - Выход

Каждая print начинает новую строку на экране.

ПРАКТИКА

Сделай меню своей игры: название, разделитель из тире, пункты «1 — Играть», «2 — Настройки», «3 — Выход».

Название игры придумай сам. Разделитель — строка из - или =.

Часть 2

Ошибки — это нормально

Как выглядит ошибка

print("Привет)
SyntaxError: unterminated string literal (line 1)
  • Python говорит тип ошибки: SyntaxError — «неправильно написано»
  • И номер строки: line 1 — где искать
  • Здесь: забыл закрыть кавычку

Топ-3 ошибки новичка

1. Забыл кавычку или скобку

print("Привет)
print("Привет"

2. Русская буква в команде

рrint("Привет") —
тут р русская. Python не знает такой команды.

3. Большая буква

Print("Привет") — Python понимает только print с маленькой.

ПРАКТИКА · ПОЧИНИ КОД

В этих трёх строках по одной ошибке. Найди и исправь:

print("Старт игры)
Print("Уровень 1")
print «Поехали!»

Часть 3

Украшаем вывод

Перенос строки: \n

print("METEOR HUNT\n1 - Play\n2 - Exit")
METEOR HUNT 1 - Play 2 - Exit

\n внутри кавычек = «здесь начни новую строку». Одна print — три строки на экране.

Пустая строка для воздуха

print("METEOR HUNT")
print()                  # пустая строка — отступ
print("Нажми ПРОБЕЛ")

print() без текста просто делает отступ. Полезно, чтобы экран не был «слипшимся».

Рисуем символами

print("*******************")
print("*   METEOR  HUNT   *")
print("*  press SPACE...  *")
print("*******************")
******************* * METEOR HUNT * * press SPACE... * *******************

Из звёздочек, тире и решёток можно собрать рамку, логотип, полоску здоровья.

Используй print, \n и print(). Это пойдёт в твоё портфолио.

Часть 4

Комментарии

Знак # — заметка для себя

# экран-заставка игры Meteor Hunt
print("METEOR HUNT")

print("1 - Play")     # пункт меню

Всё, что после # в строке, Python не выполняет. Это текст для людей.

Зачем нужны комментарии

  • Подписать, что делает кусок кода — чтобы не забыть
  • Временно «выключить» строку, не удаляя её
  • Оставить заметку «доделать потом»
# print("отладка: сюда дошли")   строка выключена
print("Игра запущена")
ПРАКТИКА

Вернись к своей заставке. В самом верху добавь комментарий с названием игры и своим именем. Подпиши комментарием, где рамка, а где меню.

Итог урока

Что ты теперь знаешь

  • print("текст") — вывод на экран
  • Кавычки и скобки — парные, закрывай тем же, чем открыл
  • \n — перенос строки, print() — пустая строка
  • Ошибка показывает тип и номер строки — читай её, не пугайся
  • # — комментарий для себя
