# 🎬 Video AI System

**Из текста сценария получается готовый вертикальный ролик. Без видеоредактора и без монтажёра.**

> 🌱 **Это мой пет-проект.** Я делаю его самостоятельно: от идеи и дизайн-системы
> до кода рендера. Здесь я учусь строить продукт целиком: продумывать архитектуру,
> вести роадмап и бэклог, работать с AI-агентом (Claude Code) как с напарником по
> разработке.

## 💡 Идея

Короткие вертикальные видео (Reels, Shorts) сейчас главный формат контента. Но
каждый ролик собирают вручную: раскадровка, типографика, тайминги, анимация,
экспорт. От ролика к ролику стиль «плывёт», а автору с готовым текстом всё равно
нужен монтажёр.

**Video AI System решает это так:**

```
текст сценария + короткие комментарии
            │
            ▼
   🧠 Planner (LLM) раскладывает смысл по сценам
            │
            ▼
   📋 Манифест сцен: какой блок, в каком порядке, сколько держать
            │
            ▼
   🎞  Remotion собирает видео из готовых пресетов и дизайн-токенов
            │
            ▼
        🎥 ролик 1080×1920
```

Главный принцип: **LLM отвечает за смысл, а не за пиксели.** Визуальная часть
детерминирована. Ролик собирается из фиксированной библиотеки анимированных блоков,
всё оформление задают дизайн-токены. Поэтому результат получается предсказуемым,
воспроизводимым и всегда в едином стиле.

## ✨ Как это выглядит в коде

Новое видео — это **один файл-манифест**: список сцен, для каждой указаны пресет,
длительность и данные.

```ts
export const VIDEO_02: SceneManifestEntry[] = [
  {
    preset:   "HookScene",
    duration: 60,              // кадры: 30 fps → 2 секунды
    data: { titleLine1: "Меньше", titleLine2: "промптов", accent: "хуже" },
  },
  {
    preset:   "GridScene",
    duration: 90,
    data: {
      items: [
        { type: "text", value: "Больше памяти" },
        { type: "text", value: "≠ умнее" },
      ],
    },
  },
];
```

TypeScript проверяет, что данные подходят выбранному пресету. Опечатка в манифесте
приводит к ошибке компиляции, а не к сломанному ролику.

## 🎨 Дизайн-система

Весь визуал подчиняется одному манифесту стиля.

| | |
|---|---|
| **Цвет** | Только чёрно-белый: режимы `paper` (белый фон) и `ink` (чёрный фон) |
| **Шрифт** | Один: Montserrat, веса Thin / Light / Regular |
| **В кадре** | Типографика, монохромные логотипы и иконки, геометрия |
| **Никогда** | Фото, видео, градиенты, свечения, эмодзи |
| **Движение** | Точные пружины без раскачки, маскированные раскрытия, knockout-типографика, инверсия через `mix-blend-mode` |

Раскладка строится по **сетке зон** (5 колонок × 9 рядов на кадр 1080×1920):
контент ставится в зону по имени (`title`, `main`, `cta`…), а не по координатам.
Safe-зоны по краям кадра всегда остаются пустыми.

## 📁 Структура

```
video-ai-system/
├── project1/               # 🎞  Remotion-приложение (рендер-слой)
│   └── src/
│       ├── videos/         #    манифесты роликов: video-XX.ts
│       ├── presets/        #    библиотека анимированных блоков + registry.ts
│       ├── primitives/     #    анимационные хуки (вся математика движения)
│       ├── common/         #    дизайн-токены, шрифты, сетка зон
│       ├── components/     #    SceneFrame (рендерер манифеста), Grid
│       └── compositions/   #    композиции Remotion
├── docs/                   # 📚 видение, архитектура, роадмап, бэклог
├── handoff.md              # 📝 состояние последней рабочей сессии
└── CLAUDE.md               # 🤖 правила для AI-агента
```
