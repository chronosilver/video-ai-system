# docs/ — карта проекта

Сервис на **React (Remotion) + Notion**: получает на вход текст сценария и короткие
комментарии, сам собирает из них короткий вертикальный ролик (reels, 1080×1920),
опираясь на собственную дизайн-систему и библиотеку пресетов.

Эта папка — **долгоживущая документация продукта**. Оперативное состояние сессий —
в `../handoff.md`, разовые отчёты — в `../outputs/`.

## Две сессии (PM + DEV)

Проект ведётся двумя параллельными сессиями Claude Code с разными ролями:

| Сессия | Папка (git-репозиторий) | Роль |
|---|---|---|
| **PM** | `~/remotion/vibe-starter` (корневой) | [roles/product.md](roles/product.md) — `docs/`, бэклог, приоритеты |
| **DEV** | `~/remotion/vibe-starter/project1` (`project1/.git`) | [roles/developer.md](roles/developer.md) — код рендер-слоя |

В начале сессии: **«Читай свою роль — `docs/roles/<product|developer>.md`»**.
Связь между сессиями — через `handoff.md` (тех-состояние) и `docs/08-backlog.md`
(задачи). Опциональная жёсткая изоляция кода — worktree:
`git -C project1 worktree add ../project1-dev -b dev`.

## Где что лежит в репозитории

```
vibe-starter/
  docs/              # ← эта документация (продукт, архитектура, роадмап, бэклог)
  brief.md           # неизменяемый бриф проекта (одна страница)
  handoff.md         # катящееся состояние: итоги последней сессии + next steps
  inputs/            # входные материалы, НЕ редактируются агентом
  outputs/           # разовые отчёты и клиентские апдейты
  CLAUDE.md          # правила для агента внутри project1 (манифест сцен, конвенции)
  project1/          # Remotion-приложение (рендер-слой)
    src/
      videos/        # манифесты видео — video-XX.ts
      presets/       # библиотека визуальных блоков + registry.ts
      primitives/    # анимационные хуки
      common/
        design-system/   # токены оформления
        grid.ts          # grid-система зон
      components/     # SceneFrame (рендерер манифеста), Grid, ui/ (shadcn)
      compositions/   # обёртки Remotion <Composition>
```

## Термины

- **Reel / ролик** — финальный вертикальный ролик 1080×1920, ~10–30 сек.
- **Сценарий (script)** — текст от пользователя: о чём ролик, по смысловым блокам.
- **Комментарии** — короткие пометки пользователя к сценарию («тут счётчик», «жёстче»,
  «убери последний блок»).
- **Manifest** — `src/videos/video-XX.ts`: декларативный массив сцен
  `{ preset, duration, data }`. Единственный per-video артефакт.
- **Preset** — React-компонент из `src/presets/`, зарегистрированный в `registry.ts`.
  Визуальный блок сцены. Собирается только из примитивов и токенов.
- **Primitive** — анимационный хук из `src/primitives/` (`useFadeIn`, `useTypewriter` …).
  Только здесь живёт математика анимации.
- **Zone** — именованная ячейка grid-системы (`title`, `main`, `cta` …). Контент
  размещается по имени зоны, не по координатам.
- **Planner** — шаг конвейера, превращающий сценарий + комментарии в manifest
  (LLM + детерминированная валидация). Ядро продукта, пока не реализован.
