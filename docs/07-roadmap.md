# 07 — Роадмап

Майлстоуны от «есть рендер-слой» до «сервис работает сам». Каждый — с критерием
выхода. Даты не проставлены намеренно (одиночный агент-разработчик); порядок фиксирован.

> ## ⚠️ Где мы сейчас
>
> **Активны только M1 и M2.** Сначала полностью закрыть **M1** (дизайн-система +
> чистка — «станок» ещё не готов), затем **M2** (Planner локально из файла).
>
> **M3–M5 (Notion, оркестрация, мультибренд, масштаб) — НЕ в работе.** Это
> продуманная наперёд цель, а не бэклог к исполнению. Не брать задачи оттуда без
> явного решения пользователя перейти дальше.

## M2 — Конвейер вручную (без Notion)

Планировщик собирает манифест из текста; всё запускается локальной командой.

**Выход:**
- `service/planner/` — `Script + Comments` (из локального файла) → `video-XX.ts`.
- LLM-шаг на `openai`, structured output, меню пресетов из `registry.ts`.
- `service/validator/` — прогон чек-листа (арифметика, safe-зоны, tsc, сборка).
- `service/render/` — headless Remotion render → `.mp4`.
- CLI: `npm run generate -- ./inputs/script-05.md` → `.mp4` + лог.
- Набор эталонов планировщика (старт: `video-01`), метрика качества раскладки.
- Зафиксированы: модель, стоимость одного ролика, время рендера.

Задачи: эпик **PLAN** + **REND**.

## M3 — Notion как интерфейс (MVP сервиса)

Пользователь работает только в Notion, ролик приезжает сам.

**Выход:**
- База «Ролики» по схеме `04-notion-workspace.md`.
- `service/ingest/` — поллинг, нормализация, машина состояний.
- `service/delivery/` — заливка `.mp4` на хостинг, запись `Video URL` / `Preview` /
  `Render log` / `Status`.
- `service/queue.ts` — последовательная обработка, лок `Generating`.
- Итеративная правка: `Done` + `Comments` → `Re-generate` с сохранением непринятых
  сцен (`Manifest JSON`).
- E2E: строка `To generate` → `Done` со ссылкой, без участия человека.
- **Метрики MVP:** время «сценарий → ролик» < 5 мин; ≥ 70% роликов без правки кода.

Задачи: эпик **NOTION** + **PLAN-4** (Re-generate).

## M4 — Мультибренд и рост библиотеки

Сервис ведёт несколько брендов; пресетов хватает на большинство сценариев.

**Выход:**
- Фабрика токенов `getTokens(brandPreset)`; `Brand preset` в Notion работает.
- +N пресетов по реальным пробелам (что планировщик чаще всего кладёт в `unmappable`).
- Гайд «как добавить пресет» + «как добавить бренд».
- Аналитика: какие пресеты используются, где планировщик ошибается.

## M5 — Надёжность и масштаб

Сервис держит нагрузку и не требует няньки.

**Выход:**
- Рендер вынесен (Remotion Lambda / воркер-пул), параллельная обработка очереди.
- Кеш рендера по хешу манифеста.
- Мониторинг: алерты на `Error`, дашборд времени/стоимости.
- Ретраи, идемпотентность Ingest/Delivery.
- Бэклог-фичи по спросу: субтитры, озвучка, A/B вариантов, экспорт форматов.
