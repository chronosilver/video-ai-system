# 01 — Продуктовое видение

## Проблема

Короткие вертикальные ролики (reels / shorts) — основной формат дистрибуции контента,
но их производство дорогое и не масштабируется:

- Каждый ролик — ручная работа в видеоредакторе: раскадровка, типографика, тайминги,
  анимация, экспорт.
- Визуальный стиль плывёт от ролика к ролику, бренд размывается.
- Автор с идеей и текстом не может сам собрать ролик за 5 минут — нужен монтажёр.
- Существующие «AI-генераторы видео» дают либо слайд-шоу из стоков, либо
  непредсказуемый результат без контроля над брендом.

## Решение

Сервис, который превращает **текст сценария + короткие комментарии** в готовый
брендированный ролик. Ключевое отличие — детерминированный визуальный слой:

- Ролик собирается из **фиксированной библиотеки пресетов**, а не рисуется с нуля.
- Всё оформление идёт через **дизайн-токены** — один источник истины для цвета,
  типографики, отступов, анимаций.
- LLM отвечает только за **раскладку смысла по сценам** (какой блок каким пресетом
  показать, в каком порядке, сколько держать), а не за пиксели.
- Результат предсказуем, воспроизводим и всегда в бренде.

## Пользователь

**Основной:** контент-мейкер / SMM / образовательный проект (референс в репозитории —
GUIDE DAO, тема AI + crypto). Пишет сценарии регулярно, хочет ролик из текста без
монтажёра, с узнаваемым стилем.

**Вторичный (позже):** агентство / команда, ведущая несколько брендов — каждый бренд
= свой набор токенов поверх общей библиотеки пресетов.

## Ценность

- **Скорость:** сценарий → ролик за минуты, без видеоредактора.
- **Консистентность:** каждый ролик в едином фирменном стиле по построению.
- **Контроль:** пользователь правит результат короткими комментариями на естественном
  языке, а не таймлайном.
- **Масштаб:** десятки роликов в неделю силами одного человека.

## Главный цикл (product loop)

```
1. Пользователь заводит строку в базе Notion:
   — текст сценария (по смысловым блокам)
   — короткие комментарии/пожелания
   — бренд-пресет (какой набор токенов)

2. Сервис забирает строку (Ingest) и планирует ролик (Planner):
   сценарий + комментарии → manifest сцен (preset + duration + data)

3. Валидация manifest: типы, safe-зоны, арифметика кадров, сборка Remotion Studio

4. Рендер ролика в .mp4 (Remotion)

5. Сервис кладёт результат обратно в Notion:
   — ссылка на ролик
   — превью
   — статус (готово / нужна правка / ошибка)

6. Пользователь смотрит, пишет комментарий «переделай блок 3 жёстче» →
   строка возвращается в очередь, цикл повторяется с сохранением остального
```

## Не-цели

- **Не** видеоредактор с таймлайном. Управление — только текстом и комментариями.
- **Не** генерация произвольной графики/видео нейросетью. Визуал — только из пресетов.
- **Не** генерация самого сценария. Текст пишет пользователь (помощь в редактуре —
  возможная фича позже, но не ядро).
- **Не** горизонтальное видео, не длинные форматы. Только вертикаль 1080×1920, ~10–40 сек.
- **Не** мультиязычная озвучка / субтитры на этом этапе (бэклог, не M0–M2).
- **Не** установка новых npm-пакетов без явного согласования.

## Метрики успеха

| Метрика | Цель на выходе M3 |
|---|---|
| Время «сценарий готов → ролик отрендерен» | < 5 мин без участия человека |
| Доля роликов, принятых без ручной правки кода | > 70% |
| Среднее число итераций «комментарий → перерендер» до принятия | ≤ 2 |
| Визуальная консистентность (ролики неотличимы по стилю) | 100% по построению |
| Стоимость одного ролика (API + рендер) | предсказуема, < X (задать в M2) |

## Принципы

1. **Детерминизм важнее «магии».** LLM выбирает из конечного меню, а не творит.
2. **Один источник истины на каждый вид решения:** токены — оформление, `grid.ts` —
   раскладка, `registry.ts` — доступные блоки, manifest — данные ролика.
3. **Агент следует правилам, а не изобретает.** Новая сцена = существующие пресеты +
   токены + примитивы. Кастомный код — только когда пресета объективно не хватает.
4. **Пользователь не трогает код.** Вся его работа — в Notion, текстом.
5. **Каждый шаг проверяем.** Нет «просто отрендерилось» — есть tsc, safe-зоны,
   арифметика кадров, сборка студии.
