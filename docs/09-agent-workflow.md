## Начало сессии

1. Прочитать `handoff.md` — где остановились, что next.
2. Прочитать `docs/02-current-state.md` — актуальный охват и техдолг.
3. Открыть `docs/08-backlog.md` — взять верхнюю незакрытую задачу активного
   майлстоуна (`docs/07-roadmap.md`), если пользователь не указал другую.
4. Не начинать задачу из следующего майлстоуна, пока не закрыт критерий выхода текущего.

## Во время работы

- **Данные и тексты ролика** — только в манифесте (`videos/video-XX.ts`).
- **Цвет / размер / шрифт** — только через токены (`design-system/tokens.ts`),
  не строками в пресетах.
- **Раскладка** — только через зоны `grid.ts` / `<GridZone>`, не `position/top/left`.
- **Анимация** — математика (`spring`, `interpolate`) только в `primitives/`.
  Пресеты вызывают хук, получают значение.
- **Новая сцена** — сначала из существующих пресетов (`registry.ts`). `GridScene` —
  способ по умолчанию. Новый пресет — только когда нужен визуальный эффект, которого
  `GridScene` дать не может.
- **Новый пресет** = компонент в `presets/` + одна строка в `registry.ts` + описание
  для каталога планировщика (DS-5).
- **Не выдумывать отсутствующие данные.** Нет подписи в брифе — плейсхолдер с
  пометкой, не фантазия.
- **Не устанавливать npm-пакеты** без явного вопроса пользователю.
- **Не выходить за область репозитория.**

## Definition of Done (любая задача с кодом)

Из `project1/CLAUDE.md` §«Проверка», обязательный минимум:

1. `npx tsc --noEmit` — 0 ошибок.
2. `npm run dev` — Remotion Studio собирается без ошибок бандла (по логу, без рендера
   кадра).
3. `TOTAL_FRAMES` == сумма `duration` в затронутых манифестах.
4. safe-зоны пусты:
   ```
   grep -rn 'zone="safe-top"\|zone="safe-bottom"\|column="safe-left"\|column="safe-right"' src/presets src/videos
   ```
   → пусто (кроме `Grid.tsx`, `grid.ts`, `GridDemo.tsx`).
5. Для задач сервиса (M2+): соответствующие юнит-тесты / eval зелёные.

**Визуальную приёмку делает пользователь.** Агент не рендерит стоп-кадры для
самопроверки внешнего вида, не гоняет `remotion still` / `render` как проверку.
`npx remotion render` — только когда пользователь явно просит финальный `.mp4`.

## Стиль кода

- TypeScript strict, без `any` (единственное исключение — задокументированная строка
  в `SceneFrame`, см. `videos/types.ts`).

- Именование и идиомы — как в соседних файлах.
