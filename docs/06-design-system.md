# 06 — Дизайн-система

Единый визуальный слой сервиса. **Пресеты и манифесты трогают только семантику**
(`text.*`, `color.*`, `space.*` …), никогда сырые значения.

Канон стиля — [`project1/src/common/design-system/about.md`](../project1/src/common/design-system/about.md)
(дизайн-манифест). Ниже — краткая версия и статус кода.

## Визуальный язык (решения владельца 2026-09-08)

Ниша: **обучающие ролики по программированию для Instagram, серийные.**

- **Строгий чёрно-белый.** Два режима кадра: `paper` (белый фон / чёрный передний
  план) и `ink` (чёрный фон / белый передний план). Полутонов нет, акцентного цвета
  нет (`#CCFF00` и `series.*` — удаляются).
- **Один шрифт — Montserrat.** Веса только Thin 100 / Light 300 / Regular 400.
  **Максимум Regular, никакого bold**, курсива, подчёркивания. Иерархия — кеглем и
  воздухом. SF Pro Display убирается.
- **Шкала кеглей:** 150 / 96 / 60 / 36 / 28 / 22.
- **В кадре только контент:** типографика, монохромные логотипы брендов (GitHub,
  Claude, Apple …), монохромные иконки (один набор), геометрия. **Никогда:** видео,
  фото, люди, скриншоты кода, цвет, градиенты, тени-свечения, эмодзи.
- **Движение — половина дизайна.** Профессиональный motion-design средствами
  Remotion: точные пружины без раскачки, маскированные раскрытия, knockout-типографика,
  инверсия по `mix-blend-mode: difference`, line-draw, переходы-объекты (wipe/clock-wipe),
  motion-blur на быстрых движениях.

Открытые вопросы (референсы, настроение, правило смены режимов, плотность, фирменная
деталь, язык текста, нумерация, субтитры, набор иконок) — §8 манифеста.

## Правила для агента

1. Новый цвет/размер/шрифт в пресете — **сначала токен в `tokens.ts`**, потом
   использование. Строк `"#xxxxxx"` в пресетах быть не должно.
2. Только два цвета. Нужна «вторичность» — меньший кегль, больше воздуха, пауза во
   времени; не серый.
3. Раскладку — только через зоны `grid.ts` / `GridZone`, не `position/top/left`.
4. Анимационную математику (`spring`, `interpolate`) — только в `primitives/`.
5. При изменении токенов — прогнать существующие `video-01..03` (визуально, силами
   владельца).
