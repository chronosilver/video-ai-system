# 06 — Дизайн-система

Единый визуальный слой сервиса. **Пресеты и манифесты трогают только семантику**
(`text.*`, `color.*`, `space.*` …), никогда сырые значения.

## Где

| Что | Путь | Роль |
|---|---|---|
| Модуль токенов | `project1/src/common/design-system/` | источник истины оформления |
| Гайдлайн | `project1/src/common/design-system/about.md` | целевые значения + правила (senior-дизайнер) |
| Описание слоёв | `project1/src/common/design-system/README.md` | навигация по модулю |
| Grid-система | `project1/src/common/grid.ts` | **раскладка** — отдельно от токенов |
| CSS-зеркало | `project1/src/index.css` (`:root` / `.dark`) | для Tailwind-классов и `ui/*` |

## Слои модуля

```
fonts.ts     SF Pro Display (заголовки) + Montserrat (текст) + mono   ┐
palette.ts   сырая палитра (OKLCH, тема shadcn)                        ├ примитивы — напрямую не трогать
scale.ts     числовые шкалы px (размер, вес, интерлиньяж, отступ …)    ┘
      │
tokens.ts    СЕМАНТИКА — правится здесь:
             text.{display,heading,subheading,title,body,caption}  (готовые объекты стилей)
             color.{text,textMuted,textFaint,bg,surface,border,accent,danger,series.*}
             space · radius · stroke · elevation · video · tint()
motion.ts    EASE-кривые
index.ts     точка входа (реэкспорт семантики)
```

## Визуальный язык (из `about.md`)

**Светлый редакционный минимализм.** Белый/светло-серый лист, тонкая почти-чёрная
типографика, много воздуха.

- **Иерархию несёт кегль и воздух, не жирность.** Максимальный вес — Regular (400).
  Medium / Bold / Black — не используются нигде.
- **Шрифты:** SF Pro Display (Thin 100 / Light 300) — заголовки; Montserrat (Light 300 /
  Regular 400) — текст, списки, подписи. Моно — системный, только для таймкодов/«кода».
- **Зелёный `#CCFF00` — акцент-исключение:** 0–1 элемент в кадре, **только заливка/
  маркер** (плашка, подсветка строки, полоска). Как текст на белом запрещён (контраст
  ~1.1:1). Для зелёной пометки текстом — `accentInk` `#4C9A00`.
- **Шкала кеглей:** 150 / 96 / 60 / 36 / 28 / 22, tracking 0. Намеренный разрыв между
  `title` (36) и `subheading` (60) — граница «читать / смотреть».
- Тени мягкие, сетка отступов 8pt, скругления 4 / 12 / 24.

## Статус (см. `02-current-state.md`)

| Аспект | Целевое (`about.md`) | В коде сейчас | Действие |
|---|---|---|---|
| Тема | светлая (bg `#FFF`, text `#141414`) | тёмная (`paletteDark`, text почти белый) | **флип** — `08-backlog.md` DS-1 |
| Веса шрифтов | Thin / Light / Regular | применено | ok |
| Шрифт-файлы | SF Pro Display `.woff2` в `public/fonts/` | нет, fallback на системный SF Pro | положить файлы (DS-4) |
| Цвета в пресетах | только `color.*` | хардкоды `rgba(255,255,255,…)`, `#1e1b4b` | пересобрать (DS-2) |
| Демо-проверка | `DesignSystemDemo` | нет | создать (DS-3) |

## Правила для агента

1. Новый цвет/размер/шрифт в пресете — **сначала токен в `tokens.ts`**, потом
   использование. Строк `"#xxxxxx"` в пресетах быть не должно.
2. Раскладку не делать через `position/top/left` — только через `GridZone` / зоны
   `grid.ts`.
3. Анимационную математику (`spring`, `interpolate`) не писать в пресетах — только в
   `primitives/`.
4. `src/index.css` синхронизировать при любой правке `palette.ts`.
5. При изменении токенов — прогнать существующие `video-01..04` (визуально, силами
   пользователя): миграция могла сдвинуть их вид.
