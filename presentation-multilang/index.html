Мультиязычный проект

Как разложить страницы на трёх языках и связать их ссылками. Только HTML, CSS и JavaScript — без единой библиотеки.

RUENDE
Зачем это нужно

Представь ситуацию

Ты собрал сайт-портфолио. Им заинтересовались заказчики из Германии и англоязычные клиенты. Теперь каждая страница нужна на трёх языках: русском, английском, немецком.

Google Translate — это костыль: кривой перевод, ломает вёрстку, не индексируется. Сделаем по-нормальному.

Задача

3 страницы × 3 языка = 9 файлов

RUENDE
Главнаяindex.htmlindex.htmlindex.html
Реквизитыcontacts.htmlcontacts.htmlcontacts.html
Инфоabout.htmlabout.htmlabout.html

Обрати внимание: имена файлов в каждом столбце одинаковые. Дальше поймёшь, почему это важно.

Главная мысль

«Страница на трёх языках» — это три файла

Не один умный файл с переключателем внутри. А три отдельных HTML-файла: одинаковый макет, разный текст. Браузер в один момент показывает только один из них.

Так делают почти все сайты компаний. Это просто, надёжно и понятно поисковикам.

Часть 1

Куда класть файлы

Способ 1. Язык в имени файла

portfolio/ index.html главная, RU index.en.html главная, EN index.de.html главная, DE contacts.html contacts.en.html contacts.de.html about.html about.en.html about.de.html
  • Все файлы на виду
  • Свалка из 9+ файлов в одной папке
  • Разные имена у одной страницы
  • Переключать языки — неудобно

Способ 2. Папка на каждый язык

portfolio/ ru/ index.html contacts.html about.html en/ index.html contacts.html about.html de/ index.html · contacts.html · about.html assets/ index.html выбор языка
  • Порядок: одна папка — один язык
  • Одинаковые имена файлов
  • Переключатель языков = смена папки
  • Так делает большинство сайтов

Способ 3. Папка на каждую страницу

portfolio/ index/ ru.html en.html de.html contacts/ ru.html en.html de.html about/ ru.html · en.html · de.html
  • Языки одной страницы рядом, но…
  • Меню приходится собирать из разных папок
  • Пути получаются длиннее и путанее
  • Для 3 страниц — перебор
Выбор

Берём Способ 2 папки по языкам

  • Внутри одного языка все ссылки простые: contacts.html
  • Переключатель языков меняет всего один кусок пути: /ru/ → /de/
  • Легко добавить 4-й язык — просто копируешь папку
  • Понятно поисковикам и понятно тебе через полгода

Наше дерево целиком

portfolio/ index.html выбор языка (редирект) ru/ en/ de/ по папке на язык index.html главная contacts.html реквизиты about.html инфо partials/ header.html общая шапка footer.html общий футер assets/ styles.css один стиль на весь сайт script.js один скрипт i18n.js словарь надписей img/

Часть 2

Правила, чтобы не запутаться

Правило 1

Одинаковые имена файлов во всех языках

Так

  • ru/contacts.html
  • en/contacts.html
  • de/contacts.html

Не так

  • ru/rekvizity.html
  • en/details.html
  • de/kontakt.html

Одинаковые имена = переключатель языков сможет собрать ссылку сам, по формуле.

Правила 2 и 3

Русский — главный. Структура — одинаковая

  • Правило 2. Сначала полностью делаешь /ru/. Потом копируешь папку в /en/ и /de/ и переводишь только текст.
  • Правило 3. Что есть в /ru/ — то есть и в /en/, и в /de/. Те же файлы, те же подпапки, та же вложенность.

Три папки-близнеца. Отличается только язык текста и атрибут lang.

Проверка

Как убедиться, что разложил верно

  • В ru, en, de — одинаковый список файлов
  • Имена файлов совпадают буква в букву
  • Открыл любую страницу — меню ведёт на соседние страницы того же языка
  • Ни одной ссылки вида C:\Users\... или ../../../ на три уровня
3
Часть 3

Ссылки — самое важное

Аналогия

Что такое путь к файлу

Путь — это адрес файла, как адрес дома. Есть два способа объяснить, куда идти:

  • От себя — «сосед справа», «этажом выше». Это относительный путь.
  • Полный адрес — «город, улица Ленина, дом 5». Это абсолютный путь.

Относительный путь

Считается от файла, где ты пишешь ссылку.

<!-- мы внутри ru/index.html -->

<a href="contacts.html">Реквизиты</a>        <!-- сосед в той же папке -->
<a href="about.html">Инфо</a>

<img src="../assets/img/logo.svg">          <!-- .. = папка выше -->
<a href="../en/index.html">English</a>      <!-- выйти и зайти в en/ -->

Минус: перенёс файл в другую папку — все ../ сломались.

Абсолютный путь от корня

Начинается со слэша /. Это «от корня сайта», всегда одинаково — из любого файла.

<a href="/ru/contacts.html">Реквизиты</a>
<a href="/en/index.html">English</a>
<img src="/assets/img/logo.svg">

<!-- работает одинаково из ru/index.html и из de/about.html -->

Корень — это папка portfolio/. / = «начни отсюда».

Правило выбора

Что где использовать

Путь от корня /

  • Меню сайта
  • Переключатель языков
  • Общие styles.css, script.js

Относительный путь

  • Картинка рядом со страницей
  • Быстрый прототип на коленке

Сомневаешься — бери путь от корня. С ним ничего не ломается при переносе.

Тег <base> — чинит ссылки одной строкой

Ставишь в <head> — и все относительные ссылки на странице считаются от указанной папки.

<!-- в <head> каждого файла папки ru/ -->
<base href="/ru/">

<!-- теперь можно писать коротко: -->
<a href="contacts.html">Реквизиты</a>   <!-- = /ru/contacts.html -->

Удобно, но помни: <base> влияет на ВСЕ ссылки страницы, включая якоря #.

Частая беда

Почему сайт ломается при двойном клике

Открыл файл двойным кликом — в адресе file:///C:/Users/.... Это не сайт, у него нет корня.

  • Пути от корня /assets/styles.css — не работают
  • fetch() общей шапки — блокируется браузером
  • Переключатель языков ведёт «в никуда»
Лечение

Запусти локальный сервер

# в терминале, из папки проекта
cd portfolio
python3 -m http.server 8000

# теперь открой в браузере:
# http://localhost:8000/

Или в VS Code: расширение Live Server → кнопка «Go Live» внизу справа. Сайт откроется на http://127.0.0.1:5500 и будет сам перезагружаться при сохранении.

Меню внутри одного языка

Шапка с меню

Одинаковый блок на всех трёх страницах папки /ru/. Ссылки — от корня.

<nav class="menu">
  <a href="/ru/index.html">Главная</a>
  <a href="/ru/contacts.html">Реквизиты</a>
  <a href="/ru/about.html">Инфо</a>
</nav>

В /en/ то же самое, но с /en/.... В /de/ — с /de/....

Подсветить текущую страницу

// script.js — сравниваем адрес страницы с href ссылки
const here = location.pathname;                  // "/ru/contacts.html"

document.querySelectorAll('.menu a').forEach(link => {
  if (link.getAttribute('href') === here) {
    link.classList.add('active');
  }
});
.menu a.active { color: #6d28d9; border-bottom: 2px solid #6d28d9; }

Одинаковая шапка на всех страницах

Часть 5

Переключатель языков

Задача

Кнопки RU / EN / DE ведут на ЭТУ ЖЕ страницу

Ты на /ru/contacts.html, жмёшь DE — попадаешь на /de/contacts.html. Не на главную немецкую, а на немецкие реквизиты.

Бесит, когда сайт кидает на главную и заставляет искать нужную страницу заново.

Секрет

Меняем только кусок с языком

/ru/contacts.html ↑↑ меняем это на en или de /de/contacts.html ← та же страница, другой язык

Работает только потому, что имена файлов одинаковые (Правило 1). Иначе формула не соберётся.

Помечаем страницу и собираем ссылку

<!-- на contacts.html любого языка -->
<body data-page="contacts">

<nav class="langs">
  <a id="to-ru">RU</a> <a id="to-en">EN</a> <a id="to-de">DE</a>
</nav>
const page = document.body.dataset.page;          // "contacts"

['ru', 'en', 'de'].forEach(lang => {
  document.getElementById('to-' + lang).href =
    '/' + lang + '/' + page + '.html';             // "/de/contacts.html"
});

Запоминаем выбор языка

// когда кликнули по языку — запомнили
localStorage.setItem('lang', 'de');
<!-- portfolio/index.html — только выбор языка -->
<script>
  const saved = localStorage.getItem('lang');
  const guess = navigator.language.slice(0, 2);     // "ru" / "en" / "de"
  const known = ['ru', 'en', 'de'];
  const lang  = saved || (known.includes(guess) ? guess : 'en');
  location.replace('/' + lang + '/index.html');
</script>

Часть 6

Кнопка → другая страница → сразу к нужному блоку

Задача

Открыть страницу и сразу промотать к блоку

На главной есть кнопка «Банковские данные». По клику открывается contacts.html — и страницу сразу прокручивает к разделу с реквизитами банка. Не к началу страницы.

Как устроен якорь

Два кусочка: id на блоке и #id в ссылке.

<!-- 1. на contacts.html вешаем id на нужный блок -->
<section id="bank">
  <h2>Банковские данные</h2>
  ...
</section>

<!-- 2. на index.html ссылка с решёткой -->
<a href="/ru/contacts.html#bank">Банковские данные</a>

Браузер откроет contacts.html, найдёт id="bank" и сам прокрутит к нему.

Кнопка или ссылка?

<!-- ХОРОШО: ссылка, стилизованная под кнопку -->
<a class="btn" href="/ru/contacts.html#bank">Реквизиты</a>

<!-- РАБОТАЕТ, но хуже: настоящая кнопка + JS -->
<button onclick="location.href='/ru/contacts.html#bank'">
  Реквизиты
</button>
  • <a> работает без JS, открывается в новой вкладке по правому клику, понятен читалкам
  • <button> — для действий (отправить форму), а не для перехода на страницу

Тонкости: плавно и под шапку

html {
  scroll-behavior: smooth;        /* плавная прокрутка к якорю */
}

#bank {
  scroll-margin-top: 90px;        /* не заезжать под фиксированную шапку */
}

#bank:target {
  background: #f4ffcc;            /* подсветить блок, к которому пришли */
  transition: background .4s ease;
}

:target — это блок, чей id стоит сейчас в адресе после #.

Тонкости: когда блок приходит через fetch

Если шапку/контент вставляешь скриптом, браузер уже промотал страницу — и промахнулся мимо ещё не существующего блока. Догоняем вручную:

window.addEventListener('load', () => {
  if (location.hash) {
    const el = document.querySelector(location.hash);   // "#bank"
    el?.scrollIntoView({ behavior: 'smooth' });
  }
});
// и переносим якорь на другой язык той же страницы
link.href = '/' + lang + '/' + page + '.html' + location.hash;

Часть 7

Правильный HTML и поисковики

Атрибут lang в теге <html>

<!-- portfolio/de/contacts.html -->
<html lang="de">

<!-- ru/... → lang="ru"      en/... → lang="en" -->
  • Браузер правильно предложит перевод
  • Читалка для незрячих выберет немецкий голос
  • Google поймёт язык страницы

hreflang и canonical

<!-- в <head> КАЖДОЙ версии страницы contacts -->
<link rel="alternate" hreflang="ru" href="https://site.com/ru/contacts.html">
<link rel="alternate" hreflang="en" href="https://site.com/en/contacts.html">
<link rel="alternate" hreflang="de" href="https://site.com/de/contacts.html">
<link rel="alternate" hreflang="x-default" href="https://site.com/en/contacts.html">

<!-- на немецкой странице: -->
<link rel="canonical" href="https://site.com/de/contacts.html">

hreflang — список всех языковых версий. canonical — «эта версия оригинал, не считай дублем».

Часть 8

Меньше копипаста — без библиотек

Один стиль и один скрипт на весь сайт

<!-- в <head> любой из 9 страниц, путь от корня -->
<link rel="stylesheet" href="/assets/styles.css">
<script src="/assets/script.js" defer></script>

Поправил цвет кнопки в styles.css — изменилось на всех девяти страницах сразу. Не надо трогать каждый файл.

Шапка и футер — один раз через fetch

<!-- на странице только пустые места -->
<div id="header"></div>
  ...
<div id="footer"></div>
// script.js
async function include(id, url) {
  const res = await fetch(url);
  document.getElementById(id).innerHTML = await res.text();
}
include('header', '/partials/header.html');
include('footer', '/partials/footer.html');

Только через localhost / настоящий сайт. И якорь # после этого лови вручную (слайд 37).

Повторяющиеся надписи — в словарь

// assets/i18n.js
const T = {
  ru: { hello: 'Привет', contacts: 'Реквизиты' },
  en: { hello: 'Hello',  contacts: 'Details'   },
  de: { hello: 'Hallo',  contacts: 'Angaben'   },
};

const lang = document.documentElement.lang;         // "de"
document.querySelectorAll('[data-i18n]').forEach(el => {
  el.textContent = T[lang][el.dataset.i18n];
});

По желанию. Удобно, когда одинаковых надписей много (меню, кнопки, футер).
