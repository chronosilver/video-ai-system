# Дизайн-манифест роликов

Роль автора: senior-дизайнер проекта. Это канон визуального стиля. Ниже —
целевые значения токенов и правила. Раскладку/позиционирование не трогаем — это
`../grid.ts`.

Ниша: **обучающие ролики по программированию для Instagram, серийные.**
Решения владельца зафиксированы 2026-09-08.

---

## 1. Визуальная идея

**Строгий чёрно-белый motion-design.** Только контент в кадре: типографика,
логотипы брендов, иконки, геометрия. Ни видео, ни фото, ни людей, ни скриншотов
кода. Смысл несут слово и движение, а не цвет и не картинка.

Ощущение: чисто, уверенно, «студийно». Каждый кадр выглядит как макет, а переходы —
как в профессиональном моушн-ролике.

Принципы:
1. **Два цвета.** Чёрный и белый. Точка.
2. **Один шрифт.** Montserrat, тонкий. Иерархия — кеглем и воздухом, не насыщенностью.
3. **Контент, а не оформление.** Логотип, слово, иконка, линия — и ничего лишнего.
4. **Движение — половина дизайна.** Статичный кадр должен быть хорош; переход между
   кадрами — тоже отдельный дизайн-объект (см. §6).

---

## 2. Режимы кадра

Ровно два. Один ролик может использовать оба (правило переключения — **открытый
вопрос**, см. §8).

| Режим | Фон | Текст / графика |
|---|---|---|
| `paper` (светлый) | `color.white` | `color.black` |
| `ink` (тёмный) | `color.black` | `color.white` |

Режим сцены (`paper`/`ink`) станет пропом сцены — «текущий передний план / фон»
разрешаются из него. Пока движка сцены нет, цвет берём напрямую (`color.black` /
`color.white` / `color.gray`).

Основа — 100% контраст. Есть **один серый** (`#8A8A8A`) — только для служебного и
второстепенного текста (`small`, реже приглушённый `body`): номера выпусков, метки,
подписи. **В `h1`/`h2` и основном сообщении серый не используем** — там иерархию
несёт кегль и воздух, не полутон. Разделительные линии — 100% контраст, волосяные.

Приём инверсии: элемент, пересекающий границу светлого и тёмного блока,
автоматически переключает цвет (`mix-blend-mode: difference`) — это часть языка, а
не спецэффект.

---

## 3. Цвет

Три значения, не больше.

| Токен | Значение | Роль |
|---|---|---|
| `color.black` | `#000000` | текст/графика на светлом; фон в режиме `ink` |
| `color.white` | `#FFFFFF` | фон в режиме `paper`; текст/графика на тёмном |
| `color.gray` | `#8A8A8A` | **только** служебный/второстепенный текст (`small`, приглушённый `body`); читается в обоих режимах |

Текст, типографика, геометрия, генерик-иконки — **только эти три значения**.
`#CCFF00`, `series.*`, `danger` — удаляются.

**Единственный цвет в кадре — фирменные логотипы** (см. §5): в оригинальных цветах
бренда. Приём как в ч/б-издании с одной цветной вклейкой — логотип «звучит» за счёт
контраста с ч/б окружением. Больше ничего цветного.

Сравнения/перечисления/шаги различаем композицией, движением и типографикой, не цветом.
«Ошибочное/неправильное» — словом, зачёркиванием (движением), иконкой.

## 4. Типографика

**Только Montserrat.** Один гарнитур на весь проект. Загрузка — через
`@remotion/google-fonts/Montserrat` (детерминированно).

### Веса
Только **Thin 100 / Light 300 / Regular 400**. **Максимум — Regular.**
Medium / SemiBold / Bold / Black / faux-bold / курсив / подчёркивание — **никогда.**
Нужно «сильнее» → больше кегль, больше воздуха, или акцент движением.

### Шкала — 4 роли

Кадр 1080×1920. Объекты стилей **без цвета** — цвет задаётся отдельно (`color.*`).

| Роль | Размер px | Вес | line-height | tracking | Когда |
|---|---:|---:|---:|---:|---|
| `text.h1` | 104 | Light 300 | 1.08 | 0 | главное сообщение сцены, 2–4 слова |
| `text.h2` | 60 | Light 300 | 1.16 | 0 | вторичный заголовок, подводка |
| `text.body` | 48 | Regular 400 | 1.4 | 0 | абзац, короткий список |
| `text.small` | 22 | Regular 400 | 1.4 | 0.04em | подпись, номер выпуска, метка (часто КАПС) |

Проверено на `video-05` (2026-09-08): h1/h2 — ок, `body` поднят 32→48 (мелкий на телефоне).
Длительность одной сцены — **60–90 кадров (2–3 сек)**, не больше.

### Правила
- Числа-callout: `h1` + `fontVariantNumeric: "tabular-nums"`.
- Тонкие `h1`/`h2` не сжимаем — трекинг 0.
- Не более одного `h1` на ролик.
- `gray` — только на `small` и приглушённом `body`; на `h1`/`h2` — никогда.

### Плотность кадра (решение владельца 2026-09-08)
- **Кадр должен быть заполнен.** Минимум **3** элемента на сцену, целевое — **4–5**
  (заголовок + 2–4 строки/лейбла/логотип/иконка-список). Пустой кадр с одной фразой
  и двумя строками — **не подходит**.
- Элементы распределяются по всей высоте контентной области (между `safe-top` и
  `safe-bottom`), а не жмутся к верху. Воздух — равномерно между элементами.
- Роли в сцене: обычно `h1`/`h2` + несколько `body`; допустимы `small`-лейблы,
  иконки-маркеры строк, логотип.

## 5. Логотипы и иконки

Логотипы и иконки — **полноправные элементы кадра**, часто главные.

### Логотипы брендов — В ОРИГИНАЛЬНОМ ЦВЕТЕ
- Полноцветные SVG (Python сине-жёлтый, JS жёлтый, React циан, VS Code синий, …).
- Это **единственный цвет в кадре** — работает за счёт контраста с ч/б окружением.
- Источник: **Devicon** (языки/инструменты, оригинальные цвета, MIT) + `gilbarbara/logos`
  (CC0) для брендов вне Devicon (Claude, Cursor). См. решение по иконкам.
- Вендорим как есть (многослойный SVG с фирменными заливками), **не перекрашиваем**.
- Масштаб — по оптической высоте прописной `h2`, не по bounding box.
- 1–2 логотипа в кадре; ряд из 3+ — горизонтальный (см. G3).

### Генерик-иконки — МОНОХРОМ
- Глифы без «своего» цвета: терминал, папка, стрелка, `git-branch`, галочка, баг…
- **Один набор** — Lucide (сетка 24px, обводка 2px). Монохром, `color.fg`.
- Иконка либо самостоятельный элемент сцены, либо маркер строки — не декор «для
  красоты».

## 6. Движение (motion-design)

Референс — профессиональные моушн-ролики. Всё средствами Remotion, всё —
чистая функция от `useCurrentFrame()`.

### Характер
- **Точный, не «мультяшный».** `spring` с высоким damping (без раскачки),
  либо кастомный bezier. Ускорение/торможение всегда, линейного движения нет.
- **Быстрые входы, спокойные удержания.** Элемент появляется за 8–14 кадров,
  живёт, уходит за 6–10.
- **Одна идея движения на сцену.** Не анимируем всё сразу — стаггер по элементам.

### Приёмы языка
- Маскированные раскрытия (текст/логотип открывается движущейся кромкой).
- Knockout-типографика: слово — «дырка» в плашке.
- Инверсия по `mix-blend-mode: difference` на пересечении блоков.
- Line-draw (рисующаяся линия/подчёркивание/соединитель) через `@remotion/paths`.
- Смена сцен — переход как объект: wipe, clock-wipe, push, а не просто cut/fade.
- Motion-blur на быстрых перемещениях (`@remotion/motion-blur`).

### Тайминг
- fps 30, кадр 1080×1920.
- Длительность ролика и сцен — от человека/Planner (`duration` в манифесте),
  не зашивается в компонент.

---

## 7. Что в кадре

**Только:** типографика, полноцветные логотипы брендов, монохромные генерик-иконки,
геометрия (`@remotion/shapes`), линии, плашки, сетка.

**Никогда:** видео, фото, люди, говорящая голова, скриншоты кода/интерфейса,
стоковые картинки, эмодзи, градиенты, тени-«свечения», цветной текст/геометрия
(цвет — только у логотипов).

## 8. Открытые вопросы (ждут решения владельца)

1. Референсы и анти-референсы.
2. Настроение в 2–3 словах.
3. Правило переключения `paper` ⇄ `ink`: на весь ролик один режим / смена по
   секциям / чередование ритмом.
4. Фирменная повторяющаяся деталь (рамка, сетка, курсор, номер выпуска, интро/аутро).
5. Язык текста на экране: RU / EN / оба.
6. Нумерация выпусков в кадре, теги тем.
7. Вшитые субтитры; дизайн под просмотр без звука.

**Решено:** плотность — 3–5 элементов на сцену, заполнять кадр (§4). Иконки —
Devicon + gilbarbara/logos (цветные логотипы) + Lucide (моно генерик).
